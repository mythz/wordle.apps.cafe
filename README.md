# 🌺 Aloha Wordle 🌴

A beautiful, modern Wordle game with a stunning Hawaiian theme built with React and Tailwind CSS.

## Features

✨ **Beautiful Hawaiian Theme**
- Tropical color gradients (pink, orange, yellow, ocean blues)
- Animated floating tropical emojis (🌺 🌴 🐚 🌊 🥥 🍍)
- Stunning background with ocean-inspired colors

🎮 **Full Wordle Functionality**
- Classic 6-guess word game
- Visual keyboard with color-coded letter status
- Real-time feedback on guesses
- Win/lose detection with celebratory modals

🎨 **Smooth Animations**
- Flip animations when revealing tiles
- Shake animation for invalid guesses
- Floating emoji backgrounds
- Smooth transitions and hover effects

## Getting Started

### Install Dependencies
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm preview
```

## How to Play

1. Guess the 5-letter word in 6 tries
2. Each guess must be a valid 5-letter word
3. After each guess, the color of the tiles will change:
   - 🟢 **Green**: Letter is correct and in the right position
   - 🟡 **Yellow/Orange**: Letter is in the word but wrong position
   - ⚫ **Gray**: Letter is not in the word
